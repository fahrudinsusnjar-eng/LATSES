# AGRI-AI Minister

Evidence-first agricultural decision-support application for ministerial and institutional use.

## Core workflow
INPUT → CLAIM IDENTIFICATION → CONTEXT → OFFICIAL SOURCES → REGULATION/PROGRAM → LOGIC CHECK → EVIDENCE/UNCERTAINTY → RESPONSE

The application is designed to distinguish claims from verified facts and to expose source, date, version and uncertainty.

This branch is intentionally isolated from the LAT technical model and AILCS reconstruction work.
