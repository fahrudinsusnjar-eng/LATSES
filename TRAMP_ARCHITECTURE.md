# TRAMP — Global Decision Intelligence

## Mission
TRAMP is the intelligence layer for ministerial and institutional decision support. Agriculture is the core domain, but decisions are evaluated across money, capital, trade, labour, migration, health, climate, resources, law and investment.

## Flow model
NOVAC → FINANSIRANJE → INVESTICIJA → PROIZVODNJA → RADNA MJESTA → MIGRACIJA → DOHODAK → POTROŠNJA → POREZI → ZDRAVLJE → HRANA → IZVOZ

## Operating pipeline
INPUT → CLAIMS → CONTEXT → OFFICIAL SOURCES → EVIDENCE → LOGIC CHECK → FLOW ANALYSIS → DECISION BRIEF

## Funding is not a catalogue
Each opportunity is modelled as a route:
SOURCE → INSTRUMENT → INTERMEDIARY → BENEFICIARY → CO-FINANCING → CONDITIONS → DEADLINE → RESULT

Supported instruments:
grant, loan, guarantee, equity, blended finance, subsidy, public budget, technical assistance.

## Evidence rule
TRAMP separates:
FACT / CLAIM / INTERPRETATION / UNCERTAINTY.
It must show the evidence behind a decisive statement and never invent a confirmed live result.

## Separation
TRAMP is separate from LAT and AILCS.
