# AILCS — Independent Project Archive

This directory is the dedicated AILCS document area inside the LATSES repository.

**Project boundary:** AILCS is independent of LATCES/LATSES. No LATCES requirements, architecture, or normative documents are to be treated as AILCS requirements merely because this directory is physically located inside the LATSES repository.

## Archive rule
- Preserve original AILCS source material.
- Preserve filenames and source identity where possible.
- Separate source evidence from reconstructed/proposed material.
- Do not silently convert LATCES material into AILCS material.
- Final AILCS documentation will be produced only after the AILCS reconstruction register is closed.
